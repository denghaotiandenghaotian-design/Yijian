# 一级建造师 · 全能备考系统

> 基于 WorkBuddy 项目框架的**开箱即用**一级建造师（四科）学习复习系统。
> 纯前端单页应用，**无需服务器、无需安装依赖**，双击 `index.html` 即可在浏览器中运行。

---

## 🚀 快速开始

1. 直接用浏览器打开本目录下的 **`index.html`**（推荐 Chrome / Edge / Firefox）。
2. 无需联网、无需 `npm install`、无需启动服务——所有数据已随包内置。
3. 学习记录、错题、进度、成就均保存在浏览器 **localStorage**，关闭页面不丢失；换设备需重新练习。

> 若浏览器对 `file://` 下的本地脚本有限制（极少情况），可在本目录执行 `python -m http.server` 后访问 `http://localhost:8000`。

## 🧩 数据格式（如需扩充题库）

每题对象（以 `window.YJ_DATA.<科目>.questions` 数组存放）：

```js
// 单选题
{ id:"E01", type:"single", chapter:"1Z101010", difficulty:3, freq:"high",
  stem:"题干", options:["A. …","B. …","C. …","D. …"], answer:["B"], explanation:"解析" }

// 多选题（5 选项，answer 为正确字母数组）
{ id:"E16", type:"multiple", chapter:"1Z101020", difficulty:3, freq:"mid",
  stem:"题干", options:["A. …","B. …","C. …","D. …","E. …"], answer:["A","C"], explanation:"解析" }

// 实务案例题
{ id:"P21", type:"case", chapter:"1A420000", difficulty:4, freq:"high",
  stem:"【背景】…", subQuestions:[ { q:"第1问…", a:"标准采分点", score:6 } ] }
```

> 应用启动时会对字段做**兼容归一化**（`stem`/`content`、`answer` 数组或字符串、`explanation`/`analysis` 均可），
> 因此直接往 `questions` 数组追加题目即可，无需改动 `app.js`。

## ⚙️ 说明

- 评分规则严格对齐官方：单选选对 1 分；多选全对 2 分、少选每对 0.5 分、错选 0 分；实务案例按采分点给分。
- 内置题库已扩充至**每科 100+ 题（经济 101、法规 103、管理 101、实务 100 含 10 道案例，合计 405 题）**，覆盖各章节高频与计算考点；仍可继续按 `assets/js/data_*.js` 格式追加。扩展题库文件为 `data_economy_s.js / _m.js`、`data_law_s.js / _m.js`、`data_management_s.js / _m.js`、`data_practice_s.js / _mc.js`，由 `app.js` 在启动时自动合并进主库。
- 新增**试卷库**：10 套模拟卷（经济2/法规2/管理3/实务3）与**近 5 年真题精编**（2021-2025 四科每年全套），均附标准答案与解析，支持逐题展开与一键导出 PDF。
- 新增**考点思维导图**：四科 45 章考点归纳（概念 + 公式），纵向导图、一键导出 PDF。
- 所有图表为手写 SVG，无任何外部 CDN 依赖，彻底离线可用。
- 顶部「重置数据」可清空本地全部学习记录（不可恢复）。
