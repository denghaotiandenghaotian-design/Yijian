# 建设工程项目管理 · 知识库

> 一级建造师《建设工程项目管理》核心框架与要点速记。

---

## 一、"三控三管一协调"框架

建设工程项目管理的核心任务，按管理职能可概括为：

| 类别 | 内容 | 目标 |
|------|------|------|
| 三控 | 进度控制、质量控制、成本控制（投资/费用控制） | 实现项目进度、质量、成本目标 |
| 三管 | 安全管理、合同管理、信息管理（含职业健康与环境管理） | 保障合规、受控、可追溯 |
| 一协调 | 组织协调 | 理顺各方关系，保证项目顺利实施 |

- 说明：安全管理是"三管"中的首要任务，也是项目管理的最重点工作。
- 适用场景：建立项目管理知识体系框架、理解项目经理职责边界。

## 二、组织论：组织结构模式

| 类型 | 特点 | 指令关系 |
|------|------|----------|
| 职能组织结构 | 多个职能部门下达指令，可能有多个矛盾指令 | 有多个指令源，易混乱 |
| 线性组织结构 | 每个下级只有一个上级，指令路径长 | 单一指令源，严谨但效率低 |
| 矩阵组织结构 | 纵向（职能部门）与横向（项目）双重领导 | 两个指令源，需协定主导 |

- 说明：组织结构模式反映组织系统中各子系统之间或各元素之间的指令关系。
- 适用场景：理解项目部设置、避免指令冲突、选择适宜的项目组织形式。

> 补充：组织论还包括组织分工（工作任务分工、管理职能分工）和工作流程组织。

## 三、赢得值法（挣值法）

三个基本参数：

| 符号 | 名称 | 含义 |
|------|------|------|
| BCWS | 计划工作预算费用（拟完工作预算费用） | 计划量 × 预算单价 |
| BCWP | 已完工作预算费用（赢得值） | 实际完成量 × 预算单价 |
| ACWP | 已完工作实际费用 | 实际完成量 × 实际单价 |

四个评价指标：

| 指标 | 公式 | 判定 |
|------|------|------|
| 费用偏差 CV | BCWP - ACWP | CV > 0 节支；CV < 0 超支 |
| 进度偏差 SV | BCWP - BCWS | SV > 0 提前；SV < 0 滞后 |
| 费用绩效指数 CPI | BCWP / ACWP | CPI > 1 节支；CPI < 1 超支 |
| 进度绩效指数 SPI | BCWP / BCWS | SPI > 1 提前；SPI < 1 滞后 |

- 说明：CV/SV 用绝对额，CPI/SPI 用相对比值，更便于不同规模项目对比。
- 适用场景：项目执行中动态监控费用与进度，及时发现偏差并纠偏。

## 四、动态控制四措施

项目目标动态控制的纠偏措施：

| 措施 | 内容 |
|------|------|
| 组织措施 | 调整组织结构、任务分工、管理职能分工、工作流程、人员等 |
| 管理措施 | 调整进度管理、合同管理、风险管理等方法与手段 |
| 经济措施 | 落实资金、资源投入、经济激励与奖罚 |
| 技术措施 | 调整设计、施工方法、施工机具、材料工艺等 |

- 说明：动态控制步骤为"目标分解→动态跟踪比较→发现偏差→纠偏→调整目标"。
- 适用场景：进度/成本/质量目标偏离后的纠偏方案制定。

## 五、施工组织设计分类

| 分类 | 编制对象 | 深度 |
|------|----------|------|
| 施工组织总设计 | 整个建设工程项目 | 统筹全局 |
| 单位工程施工组织设计 | 单位工程 | 指导单位工程施工 |
| 分部（分项）工程施工组织设计（施工方案） | 特别重要/技术复杂的分部分项 | 具体施工作业指导 |

- 说明：规模大、结构复杂或危险性较大的分部分项需编制专项施工方案，必要时组织专家论证。
- 适用场景：区分不同层级施组编制范围与审批权限。

## 六、网络计划：六时参数与关键线路

### 1. 六时参数
| 参数 | 含义 |
|------|------|
| ES（最早开始） | 工作最早可开始时间 |
| EF（最早完成） | ES + 持续时间 |
| LS（最迟开始） | 不影响总工期的最迟开始 |
| LF（最迟完成） | LS + 持续时间 |
| TF（总时差） | 不影响总工期的前提下可机动时间 = LS-ES = LF-EF |
| FF（自由时差） | 不影响紧后工作最早开始的前提下可机动时间 |

### 2. 关键线路与关键工作
- 关键线路：总持续时间最长的线路；网络计划中至少有一条，可能多条。
- 关键工作：关键线路上的工作，总时差最小（通常为 0）。

### 3. 总时差与自由时差
- 总时差 TF：本工作可延误而不影响总工期的时间。
- 自由时差 FF：本工作可延误而不影响紧后工作最早开始的时间，FF ≤ TF。

- 说明：关键工作总时差 = 0（计划工期 = 计算工期时）。
- 适用场景：进度计划优化、工期压缩（赶工）优先选关键线路上的工作。

## 七、质量 / 安全 / 合同管理要点

### 1. 质量管理
- 质量控制是"三控"之一，坚持"质量第一、预防为主"。
- 三阶段控制：事前、事中、事后控制。
- 三全管理：全面、全过程、全员参与。
- 检验批→分项→分部→单位工程逐级验收。

### 2. 安全管理
- 安全管理是项目管理的首要任务。
- 坚持"安全第一、预防为主、综合治理"。
- 危险性较大的分部分项工程需编制专项方案，超规模的须专家论证。
- 安全事故处理"四不放过"：原因未查清、责任人未处理、整改措施未落实、有关人员未受教育不放过。

### 3. 合同管理
- 合同文件优先顺序：合同协议书 > 中标通知书 > 投标函及附录 > 专用合同条款 > 通用合同条款 > 技术标准和要求 > 图纸 > 已标价工程量清单等。
- 索赔成立三要件：事件造成损失、非己方责任、按程序时限提出。
- 适用场景：处理工程变更、签证、工期与费用索赔。
