# 建筑工程实务 · 考点速查

> 一级建造师《建筑工程管理与实务》高频数字与构造、施工、验收速查手册。

---

## 一、建筑构造数字

### 1. 楼梯
| 项目 | 数字要求 |
|------|----------|
| 每段楼梯踏步数 | 3～18 级（不少于 3，不大于 18） |
| 平台（休息平台）处净高 | ≥ 2.0 m |
| 梯段（斜段）净高 | ≥ 2.2 m |
| 扶手高度 | 自踏步前缘线起 ≥ 0.9 m（靠楼梯井一侧水平扶手＞0.5m 长时≥1.05m） |
| 梯段净宽 | 供日常主要交通用的楼梯梯段净宽按使用人数确定，且≥1.1 m（住宅等另有规定） |

### 2. 防火分区
- 不同耐火等级、不同建筑类型的防火分区最大允许建筑面积不同（如一、二级耐火等级高层民用建筑防火分区≤1500 ㎡，多层≤2500 ㎡，设自动灭火系统可按规定增加）。
- 适用场景：判断平面布置是否满足防火分隔要求。

### 3. 屋面与防水等级
| 项目 | 等级划分 |
|------|----------|
| 屋面防水等级 | Ⅰ级（重要建筑、高层建筑，两道防水设防）、Ⅱ级（一般建筑，一道设防） |
| 地下工程防水等级 | 一级～四级（一级不允许渗水、结构表面无湿渍；四级有少量漏水点） |
| 建筑幕墙防水 | 按气密、水密、抗风压等性能指标分级 |

## 二、抗震构造

| 项目 | 要点 |
|------|------|
| 抗震设防烈度 | 一般地区按 6、7、8、9 度设防；建筑按"小震不坏、中震可修、大震不倒"三水准设防目标 |
| 框架抗震等级 | 根据设防烈度、结构类型、房屋高度划分为一、二、三、四级，一级最严 |
| 锚固长度 | 受拉钢筋基本锚固长度 l_ab 依钢筋种类、混凝土强度等级、抗震等级（l_aE）确定 |
| 箍筋加密区 | 框架柱端、梁端及节点核心区按抗震等级要求加密 |
| 构造柱 / 圈梁 | 砌体房屋按设防要求设置，增强整体性与延性 |

- 适用场景：判断构件抗震构造措施是否满足等级要求。

## 三、装饰装修

### 1. 吊顶工程
- 主龙骨吊点间距、起拱高度按设计；不上人吊顶主龙骨间距≤1200 mm，上人吊顶≤1000 mm。
- 吊顶内管道、设备调试合格后隐蔽验收方可封板。
- 重型灯具、电扇及其他重型设备严禁安装在吊顶龙骨上，应设独立吊杆。

### 2. 幕墙工程
- 幕墙性能：抗风压、气密、水密、热工、隔声、层间变形等。
- 立柱与主体结构连接：每个连接部位的螺栓≥2 个，且应有可靠防松脱措施。
- 硅酮结构密封胶使用前须做相容性试验；隐框、半隐框幕墙严禁现场打注（须在工厂注胶）。
- 幕墙防雷：铝合金立柱与主体防雷体系可靠连接。

## 四、材料速记

### 1. 水泥
| 项目 | 要求 |
|------|------|
| 初凝时间 | ≥ 45 min（六大通用水泥通用要求） |
| 终凝时间 | 硅酸盐水泥 ≤ 6.5 h（390 min）；其他通用硅酸盐水泥 ≤ 10 h |
| 安定性 | 必须合格，不合格严禁使用 |
| 强度等级 | 按 3 d、28 d 抗压/抗折强度划分 |

### 2. 钢筋
- 力学性能：屈服强度、抗拉强度、伸长率；工艺性能：冷弯。
- 钢筋连接：绑扎搭接、机械连接、焊接，按规格与部位选用。
- 抗震钢筋（牌号带 E）：强屈比、超屈比、最大力总延伸率满足专门要求。

### 3. 混凝土
- 强度等级按立方体抗压强度标准值划分（C15～C80）。
- 耐久性指标：抗渗（P）、抗冻（F）、氯离子含量、碱含量等。
- 坍落度依施工工艺（泵送、自密实等）确定。

### 4. 玻璃
- 安全玻璃：钢化玻璃、夹层玻璃、防火玻璃（用于天窗、隔断、幕墙等规定部位）。
- 中空玻璃用于节能；镀膜玻璃注意膜面朝向。

## 五、施工技术

### 1. 大体积混凝土
- 定义：混凝土结构物实体最小尺寸≥1 m，或预计会因水泥水化热引起温度应力、产生裂缝的混凝土。
- 控制要点：选用中低热水泥、降低入模温度、分层浇筑、保温保湿养护、测温监控里表温差（不宜＞25 ℃）。
- 适用场景：基础底板等大体积构件裂缝防控。

### 2. 脚手架
- 立杆基础稳固、扫地杆齐全；剪刀撑按规范设置。
- 作业层脚手板铺满铺稳，外侧设栏杆与挡脚板及密目安全网。
- 严禁超载，拆除按"后搭先拆、先搭后拆"顺序。

### 3. 模板工程
- 模板及支架应有足够承载力、刚度与稳定性。
- 拆模：底模及支架拆除时混凝土强度须达到设计要求/规范规定（如板跨≤2 m 达 50%、>8 m 达 100% 等）。
- 高大模板（搭设高度、跨度、施工总荷载超规定）须专项方案并专家论证。

### 4. 地基与基础
- 基坑支护：排桩、地下连续墙、土钉墙、内支撑等，按开挖深度与环境选用。
- 基坑监测：支护结构位移、周边沉降、地下水位等。
- 验槽：基槽开挖至设计标高后，由勘察、设计、监理、施工、建设各方共同验槽。

## 六、质量验收

| 层次 | 划分/组织 | 说明 |
|------|-----------|------|
| 检验批 | 按楼层、施工段、工程量划分，专业监理工程师组织验收 | 验收最小单元 |
| 分项工程 | 由检验批组成，监理工程师组织验收 | 按工种、材料、工艺划分 |
| 分部工程 | 由分项工程组成，总监理工程师组织（勘察、设计单位参加地基与主体等） | 按专业性质、建筑部位划分 |
| 单位工程 | 由分部工程组成，建设单位组织竣工验收 | 具备独立施工与使用功能 |

- 说明：验收合格条件——检验批主控项目、一般项目均合格；分项、分部、单位工程逐级汇总评定。
- 适用场景：判断验收组织权限与程序、资料归档要求。

---

> 注：以上数字与等级以最新版《建筑工程管理与实务》教材及现行国家标准（GB 系列）为准，复习时以教材表述为准。
