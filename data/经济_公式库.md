# 建设工程经济 · 公式库

> 一级建造师《建设工程经济》核心公式体系。每个公式配一句话说明与适用场景，供速记与刷题使用。

---

## 一、资金时间价值

### 1. 单利
**I = P · i · n**

- 说明：利息 = 本金 × 年利率 × 计息期数，仅对本金计息、利不生利。
- 适用场景：短期或约定按单利计息的借贷，用于与复利对比计算利息总额。

**F = P(1 + i·n)**（单利本利和）

- 说明：本利和 = 本金 ×（1 + 利率 × 期数）。
- 适用场景：单利条件下求若干年后的本利和。

### 2. 复利
**F = P(1 + i)^n**

- 说明：复利本利和 = 本金 ×（1 + 利率）的 n 次方，利滚利。
- 适用场景：贷款、投资等通常按复利计息时，求 n 期末的终值。

**P = F / (1 + i)^n = F(1 + i)^-n**

- 说明：现值 = 终值按复利折现到当前，折现系数 (P/F, i, n)。
- 适用场景：已知未来一笔资金的终值，求现在应投入（或现值的）金额。

### 3. 年金与等值换算
**F = A · [(1 + i)^n - 1] / i**（年金终值，系数 F/A）

- 说明：每期末等额存入 A，n 期后按复利累积的终值。
- 适用场景：等额还贷、等额储蓄到期一次取出的本息和。

**P = A · [(1 + i)^n - 1] / [i(1 + i)^n]**（年金现值，系数 P/A）

- 说明：未来 n 期等额年金 A 折算到现在的现值。
- 适用场景：分期付款、等额租金、等额年金方案的现值比较。

**A = P · i(1 + i)^n / [(1 + i)^n - 1]**（资金回收，系数 A/P）

- 说明：已知现值 P，求在 n 期内等额回收的每期金额。
- 适用场景：等额还本付息方案，计算每期应还金额。

**A = F · i / [(1 + i)^n - 1]**（偿债基金，系数 A/F）

- 说明：为在 n 期末积累终值 F，每期需等额存入的金额。
- 适用场景：为将来某笔大额支出（如设备更新）设立等额储备金。

## 二、名义利率与有效利率

**i_eff = (1 + r/m)^m - 1**

- 说明：有效利率 =（1 + 名义利率/计息次数）的 m 次方减 1。
- 适用场景：名义利率 r 一年内计息 m 次时，换算为可比的年有效利率，用于不同计息周期方案的比较。

> 当 m = 1 时，i_eff = r；计息次数越多，有效利率越高。

## 三、经济效果评价指标

### 1. 财务净现值 FNPV
**FNPV = Σ(CI - CO)_t · (1 + i_c)^-t**

- 说明：按基准收益率 i_c 将各年净现金流量折现并求和。
- 适用场景：FNPV ≥ 0 项目财务可行；多方案比选时越大越好。

### 2. 财务内部收益率 FIRR
**Σ(CI - CO)_t · (1 + FIRR)^-t = 0**

- 说明：使净现值为零的折现率，即项目实际可达到的收益率。
- 适用场景：FIRR ≥ 基准收益率 i_c 时项目可行；不受人为设定 i_c 影响，便于独立判断。

### 3. 投资回收期
**静态投资回收期（Pt）**：累计净现金流量由负转正的年份
- 说明：不考虑资金时间价值，用净收益收回全部投资所需年限。
- 适用场景：粗略判断回收快慢，宜短不宜长。

**动态投资回收期（P't）**：考虑折现后累计净现值由负转正
- 说明：考虑资金时间价值，折现后收回投资所需年限。
- 适用场景：比静态更科学，但一般仍作为辅助指标。

### 4. 总投资收益率 ROI
**ROI = EBIT / TI × 100%**

- 说明：息税前利润与项目总投资之比。
- 适用场景：考察项目总投资的盈利水平，达到行业参考值以上为宜。

### 5. 资本金净利润率 ROE
**ROE = NP / EC × 100%**

- 说明：净利润与项目资本金之比。
- 适用场景：反映投资者自有资金的盈利水平。

## 四、盈亏平衡分析

**BEP(Q) = C_F / (p - C_u - T_u)**

- 说明：盈亏平衡点产量 = 年固定成本 /（单位售价 - 单位变动成本 - 单位税金）。
- 适用场景：求不亏不盈的最低产销量；BEP 越低，项目抗风险能力越强。

**BEP(%) = BEP(Q) / Q_d × 100%**（生产能力利用率）

- 说明：盈亏平衡产量占设计生产能力的比例。
- 适用场景：用利用率表达盈亏平衡点，便于判断项目负荷安全度（越小越安全）。

## 五、敏感性分析、设备经济寿命、价值工程、租金

### 1. 敏感性分析
**敏感度系数 S_AF = ΔA/A ÷ ΔF/F**

- 说明：评价指标相对变化率与不确定因素相对变化率之比。
- 适用场景：|S_AF| 越大，该因素越敏感；排序后优先控制最敏感因素。

### 2. 设备经济寿命
**N_0 = √[2(P - L_N) / λ]**（年均成本最低法，λ 为年劣化值）

- 说明：使设备年平均使用成本最小的年限。
- 适用场景：确定设备最佳更新时机，避免过早或过晚更换。

### 3. 价值工程
**V = F / C**

- 说明：价值 = 功能 / 寿命周期成本。
- 适用场景：V < 1 成本偏高需改进；以提高功能或降低成本提升价值。

### 4. 设备租金计算
**附加率法：R = P·(1 + N·i) / N + P·r**

- 说明：每期租金 = 本金均摊本息 + 本金 × 附加率。
- 适用场景：融资租赁中按附加率法计算每期应付租金。

**年金法：R = P·i(1+i)^N / [(1+i)^N - 1]**

- 说明：将设备价款按年金方式分摊到每期。
- 适用场景：融资租赁中按等额年金法计算每期租金。

## 六、财务会计

### 1. 权责发生制
- 说明：以权利和责任的发生（而非现金收付）确认收入和费用。
- 适用场景：企业会计核算基础，正确匹配各期收入与费用。

### 2. 偿债能力比率
**流动比率 = 流动资产 / 流动负债**

- 说明：反映短期偿债能力，一般 ≥ 2 较安全（实务以教材表述为准）。
- 适用场景：债权人评估企业能否按期偿还短期债务。

**速动比率 = (流动资产 - 存货) / 流动负债**

- 说明：剔除变现较慢的存货后衡量即时偿债能力，一般 ≥ 1 较安全。
- 适用场景：更严格地考察企业短期支付能力。

### 3. 资产负债率
**资产负债率 = 负债总额 / 资产总额 × 100%**

- 说明：反映总资产中举债筹资的比重，衡量长期偿债风险。
- 适用场景：债权人关注其是否过高，所有者关注财务杠杆；需适度。

### 4. 资产管理比率（补充）
**总资产周转率 = 主营业务收入 / 资产总额**

- 说明：反映资产利用效率和营运能力。
- 适用场景：评价企业资产创造收入的快慢。
